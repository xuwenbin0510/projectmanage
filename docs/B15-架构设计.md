## 0. 设计总览（先读这一节）

本批是**纯前端增量、零后端改动、零 schema 变更**：不新增接口 / 路由 / 表字段，所有数据来自 `GET /api/workbench` 既有返回值（`data.myTasks`、`dashboard.*` 聚合）或复用既有 `api.listWbs(projectId)` / `api.listMilestones(projectId)` 局部拉取。共改动 **6 个文件**（5 改 1 新建），交付 2 个任务（T01 基础层 / T02 集成层）。

## 1. 实现方案（Implementation Approach）

### 1.1 核心难点

| 难点 | 方案（行内一句话） |
|---|---|
| 全局抽屉要跨项目聚合，但零后端 | 复用 `dashboard.overdue` 拿「涉及项目清单」，抽屉内 `Promise.all` 并行 `listWbs + listMilestones` 局部拉取（沿用 B13 模式，不写 `wbsStore`，关闭即丢弃） |
| 跨项目里程碑 id 可能冲突 | 里程碑映射改用 `projectId::milestoneId` 复合 key（两种模式统一走复合 key，单项目模式行为不变） |
| 抽屉行数（含他人）与卡片数值（仅我）对不上 | all 模式副标题注明「含他人任务，可开仅看我」（P1-3） |
| 进度环要可点但 `ProgressDonut` 无点击能力 | 加 `onDrill?: (segment: ProgressSegment) => void`，透传 `DonutChart.onSegmentClick`，模式与 `PriorityDonut` 完全一致 |
| 我的任务明细要「零额外请求」 | `MyTasksDrawer` 纯受控：`tasks` 由 `WorkbenchPage` 传 `sortedTasks` 快照（`useMemo` 缓存、P0 置顶、与区块同源同序），抽屉内只做本地筛选/分页 |
| 空态文案要区分「无任务 / 已完成段 / 筛选无匹配」 | `MyTasksDrawer` 空态三分支 + 全局抽屉空态按 mode 分支（P1-4） |

### 1.2 技术选型（全部复用既有资产，零新依赖）

- 框架：Vite + React 18 + TS + MUI（`@mui/material@^5.16.7`）+ Tailwind，图表 `@mui/x-charts@^7.12.0`（既有）。
- 抽屉骨架：MUI `Drawer anchor="right"` 420px / `maxWidth:'92vw'` + 关闭 `IconButton` + ESC/遮罩（复用 `OverdueTaskDrawer` 既有写法）。
- 表格：`DataTable<T>`（`web/src/components/common/DataTable.tsx`），零新依赖。
- 无新路由：跳转一律 `ROUTES.projectWbs(id)` / `ROUTES.projectReports(id)`。
- 无新枚举：优先级下拉走 `PRIORITY_OPTIONS`；状态下拉走行内保序去重（同 B13 `statusOptions` 模式）。

### 1.3 架构模式

- 页面层 `WorkbenchPage` 持有全部抽屉受控状态（`ovDrawer` 加 `mode`、新增 `myTasksDrawer`），组件自包含（props 驱动、内部状态关闭即复位），延续 B13/B14 的「受控抽屉 + 局部 state」模式。
- 数据流：`GET /api/workbench → buildDashboard/sortByPriority（useMemo）→ 传入抽屉`；全局抽屉再局部 `listWbs/listMilestones` 下钻。
- 纯函数复用：`dashboardAgg`（`splitOverdueByStatus`/`comparePriority`/`sortByPriority`/`aggregateTaskProgress` 语义）与 `utils/date` 为口径单一真源。

```ts
/** 进度段分类：口径镜像 dashboardAgg#aggregateTaskProgress（done=完成 / active=进行中+待评审 / pending=待办+阻塞+未知） */
function progressSegmentOf(status: TaskStatus): ProgressSegment {
  switch (status) {
    case '完成': return 'done';
    case '进行中':
    case '待评审': return 'active';
    case '待办':
    case '阻塞':
    default: return 'pending';
  }
}
```

- **零后端**：本批不新增任何接口 / 路由 / 表字段 / schema；`git diff` 不得出现 `server/**` 与 schema 文件。
