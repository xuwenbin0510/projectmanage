## 0. 产品目标（一句）

让「工时账」从**单点只读展示**升级为**可分析、可比较**：项目经理在项目内任一页都能看到「估算（人日）vs 累计实际（人日）」的对比与按里程碑/任务的投入汇总，且任务列表、看板卡片同步展示累计实际工时，支撑投入评估与超支预警，无需手工翻日志算账。

## 3. 关键交互说明

### 3.1 报表页布局（B9-R1/R2/R3）

**位置**：项目详情 Tab「工时报表」（`/projects/:id/effort`），入口与「WBS」「看板」同级。

**页面结构（自上而下）**：

1. **汇总卡片区**（一行 4~5 张卡片，沿用品牌青）：
   - 估算总和（人日）：Σ 全部叶子 `estimateDays`；
   - 实际总和（人日）：Σ 全部叶子 `effortHours`（口径 = 工作日志累计，与 WBS 出参一致）；
   - 差值（人日）：实际 − 估算，负数（结余）绿色、正数（超支）红/橙；
   - 偏差率（%）：见 Q4（估算为 0 显示「—」）；
   - 超支任务数：实际 > 估算 的任务（叶子）计数，>0 高亮提示。
2. **明细表格区**：
   - 默认展示 **WBS 树结构**（沿用缩进/层级），里程碑（父）行可折叠展开子任务；
   - 行内列：节点（名称 + 编码）、负责人、估算人日、累计实际工时（人日）、差值、偏差率、进度；
   - **排序**：点击表头切换升/降序（沿用 `ReportsPage` 现有 `TableSortLabel` 交互风格）；排序时同层级内比较（不跨层混排），推荐默认按「节点层级 + 实际工时降序」；
   - **超支行高亮**：差值 > 0 时该行差值/偏差率着色 + 可选「超支」Chip；
   - 父节点（里程碑/有子节点任务）行实际工时 = Σ 子任务（沿用 `effortHours` 口径），差值/偏差率按 Σ 计算。
3. **展开明细（B9-R4）**：任务行最右侧「展开」按钮（或行点击）→ 下方展开区列出该任务实际工时构成：
   - 每行：周次（如 `2026-W33`）、提交人、提交时间、当周实际工时（人日）；
   - 底部小计 = 该任务 `effortHours`（校验一致，不一致应视为数据异常并提示，见验收 B9-R4 ④）。

### 3.2 报表数据与口径（B9-R2/R3/R4）

- **服务端聚合接口（推荐新增）**：`GET /api/projects/:id/effort-report`（或扩展 `listWbs` 出参，架构师定，推荐独立接口避免污染列表契约）返回：
  - `summary`：`estimateTotal` / `actualTotal` / `diff` / `diffRate` / `overrunCount`（叶子口径）；
  - `rows`：节点树（复用 `decorateEffort` 的 `effortHours`/`effortChildCount`）+ `estimateDays` + `progress` + `ownerName`；
  - `effortBreakdown`（可选，懒加载）：map `nodeId → [{ week, reporterName, submittedAt, weekActualDays }]`。
- **口径**：估算 = `estimateDays`（人日，规划期填）；实际 = `effortHours`（人日，日志累加，B8 语义）；父节点实际 = Σ 直接子节点（读时汇总，不信任前端）。差值/偏差率见 Q4。
- **周报贡献来源**：`work_report_tasks`（按 `wbs_node_id`）join `work_reports`（周次/提交人/提交时间/状态），仅统计**已提交（非草稿）**日志；编辑冲正后自动反映新值（B8 已保证节点累计一致，明细直接按当前日志行聚合）。
- **空态**：无任务或全部 `effortHours = 0` 时，汇总卡片照常显示（实际 = 0），表格正常渲染，不阻断页面；无周报明细的任务展开区显示「暂无周报贡献」。

### 3.3 WBS 列表加列（B9-R5）

**位置**：`WbsPage.tsx` 树行节点名右侧（B8 弹窗内只读展示的**同一口径**上移到列表）。

- 叶子任务：显示「累计实际工时（人日）」只读值（如 `1.5`）；
- 父节点：显示 Σ 值并附「Σ」前缀 + tooltip「由 N 个子任务汇总（由工作日志累计）」；
- 与现有「工时估算（人日）」（`fmtDays(node.estimateDays)`）并列展示，建议格式 `估算 x.x · 实际 x.x`（单行小字，避免占用过多横向空间），tooltip 全量说明；
- 数据直接取 `listWbs` 出参 `effortHours`（B8 已带），**前端零聚合**，仅新增展示列。

### 3.4 看板卡片加副信息（B9-R6）

**位置**：`BoardPage.tsx#CardBody`（现有副信息已有 `fmtDays(card.estimateDays)`）。

- 卡片副信息新增「实际 x.x 人日」，与现有估算并列展示：`估 x.x / 实 x.x 人日`；
- 超支（实际 > 估算）时「实」值着色（红/橙）提示；
- 父节点卡片（若有）显示 Σ 值（沿用 `effortHours` 出参）。
