## 二、B9 专项用例清单（接口层，`scripts/qa_b9_verify.mjs` 自动断言）

| # | 断言点 |
|---|--------|
| S-1 | 未登录访问 `GET /projects/:id/effort-report` → 401 `E_UNAUTHORIZED`；项目不存在 → 404 `E_NOT_FOUND` |
| S-2 | 响应结构 `{projectId, summary, rows[], effortBreakdown{}}`，无 snake_case |
| S-3 | 汇总口径：`estimateTotal`/`actualTotal`/`diff`/`diffRate` = Σ 叶子；`overrunCount` 独立判定 |
| S-4 | 行口径：父 `estimateDays`=Σ 子树叶子、父 `effortHours`=Σ 直接子；叶与 listWbs 出参一致 |
| S-5 | 偏差率边界：估算 0 → `diffRate=null`；估 0 且实>0 → `isOverrun=true`（独立于偏差率） |
| S-6 | 估算总和 0 → `summary.diffRate=null` |
| S-7 | breakdown 过滤：仅已提交 & `selected=1` & `week_actual_days>0`；周倒序；草稿不出现 |
| S-8 | breakdown 小计 = 该节点 `effortHours`（|差|≤0.01） |
| S-9 | 编辑已提交日志冲正 → effort-report 行/汇总/breakdown 同步 |
| S-10 | WBS 移动/删除后 effort-report 与 listWbs 口径一致（叶值相等、父 Σ 相等） |
| S-11 | 无节点项目 → 空结构不崩（rows 空、summary 全 0、breakdown 空对象） |
| S-12 | 里程碑 badge：行带 `milestoneCode`/`milestoneName`（一次查表，前端零状态） |
| S-13 | 前端契约：`getEffortReport` mock 与 HTTP 同构（同一份 EffortReport 类型）；`npx tsc --noEmit` 通过 |
